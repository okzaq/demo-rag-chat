# ZaikoMaster クラウド在庫管理システム 取扱説明書

※ 本書は架空の製品「ZaikoMaster」の架空のマニュアルです（デモ用に作成）。

## 1. 動作環境

ZaikoMaster はクラウド型の在庫管理システムです。以下の環境で動作します。

- 対応ブラウザ: Chrome / Edge / Safari の最新版と、その1つ前のバージョン
- ネットワーク: 常時インターネット接続が必要（オフライン動作は非対応）
- 推奨画面解像度: 1280×800 以上
- モバイル: iOS 16 以降 / Android 12 以降の専用アプリを提供

## 2. 初期設定

### 2.1 管理者アカウントの作成

契約完了後に届く「開通のご案内」メールのURLから、管理者アカウントを作成します。
URLの有効期限は発行から72時間です。期限切れの場合はサポート窓口へ再発行を依頼してください。

### 2.2 倉庫の登録

管理画面の「設定 > 拠点管理」から倉庫を登録します。登録できる倉庫数はプランによって異なります。

- スタートプラン: 1拠点
- スタンダードプラン: 5拠点まで
- エンタープライズプラン: 無制限

### 2.3 商品マスタの取り込み

商品マスタはCSV一括取り込みに対応しています。1回の取り込み上限は10,000行、
ファイルサイズ上限は20MBです。文字コードはUTF-8とShift_JISに対応しています。
取り込みエラーが発生した行はスキップされ、エラー内容が「取込履歴」画面からダウンロードできます。

## 3. 入出庫の操作

### 3.1 入庫登録

「入庫 > 新規入庫」から登録します。バーコードスキャナ（USB接続・HIDモード）での連続読み取りに対応しています。
入庫予定データを事前に取り込んでおくと、予定との差異が自動でハイライトされます。

### 3.2 出庫登録

出庫は「ピッキングリスト発行 → ピッキング → 出庫確定」の3ステップで行います。
出庫確定後の取り消しは当日中のみ可能です。翌日以降は「棚卸調整」として処理してください。

### 3.3 在庫アラート

商品ごとに安全在庫数を設定すると、在庫がしきい値を下回った時点でメールとアプリ通知が送られます。
通知先は最大10アドレスまで登録できます。

## 4. 棚卸

棚卸は「一斉棚卸」と「循環棚卸」の2方式に対応しています。
一斉棚卸中は入出庫操作がロックされます。循環棚卸では対象ロケーションのみがロックされます。
棚卸差異が5%を超えるロケーションは、確定前に管理者の承認が必要です。

## 5. 外部連携

- 対応EC: 楽天市場・Yahoo!ショッピング・Shopify（在庫数の自動連携は15分間隔）
- 会計連携: freee・マネーフォワード クラウド（日次で仕訳データを出力）
- API: REST API を全プランで提供。認証はAPIキー方式で、レート制限は毎分120リクエストです。

## 7. サポート

- 受付時間: 平日 9:00〜18:00（土日祝・年末年始を除く）
- 窓口: チャットサポート（管理画面右下）およびメール
- 障害情報: ステータスページで公開（99.9%の月間稼働率をSLAとして保証するのはエンタープライズプランのみ）
